# 🧮 Calculadora Java

Pequeña aplicación de consola desarrollada en **Java** que permite realizar operaciones matemáticas básicas ingresando una expresión por teclado.

El programa interpreta operaciones escritas por el usuario y calcula el resultado automáticamente.

---

## 🚀 Ejemplo de uso

El usuario ingresa una operación: 2 + 3

Salida: 5

También permite multiplicar tres números: 2 * 3 * 4

Salida: 24

---

## ⚙️ Funcionalidades

- Suma
- Resta
- Multiplicación (2 o 3 números)
- División
- Lectura de operaciones desde consola

---

## 🛠 Tecnologías utilizadas

- Java
- Scanner
- Programación orientada a objetos
- Manejo de Strings
